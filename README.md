# Klic4change
Chrome Extension: Reporting underage users made easy.
When you click the extension's lock icon in the Chrome toolbar, a small popup opens showing four platform logos: Facebook, Instagram, Snapchat and TikTok. Clicking a logo opens that platform's official reporting or help form in a new tab, so a user can report an account that seems to belong to someone below the platform's minimum age. For example, the Snapchat link is pre-filled with the report category for users under 13.
